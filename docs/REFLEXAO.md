# Reflexão — sugestão para revisão do estudante

A IA contribuiu para organizar as responsabilidades de Model, View e Controller.
A integração substituiu as linhas temporárias do navegador por operações no banco.
A revisão identificou a necessidade de validar datas, descrição e identificadores no servidor.
Consultas parametrizadas, escape HTML e proteção CSRF foram incorporados ao código.
A remoção passou a conferir também o usuário responsável pela formação.
Os exemplos do enunciado foram adaptados aos campos que já existiam no projeto.
O README e o roteiro ajudam a reproduzir a atividade e verificar os resultados.
Os testes não foram executados nesta coautoria e a homologação ainda precisa ser concluída.
